# Multi-Step React Form

A multi-step form application built with React and React-Bootstrap. It guides users through several pages of questions, tracks progress visually, and displays a confirmation message on submission.

## Features

- Multi-page form with configurable questions (`Questions.js`)
- Visual step progress bar
- Previous/Next navigation, with Submit on the final page
- Per-page answer state tracking
- Confirmation screen with option to start over
- Responsive Bootstrap layout

## Tech Stack

- **Frontend**: React, React-Bootstrap

## Getting Started

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Available Scripts

| Command | Description |
|---------|-------------|
| `npm start` | Run the app in development mode |
| `npm test` | Launch the test runner |
| `npm run build` | Build the app for production |
