# web-dev-projects-main

A curated collection of web development projects built and maintained by **Shivang1538**.

## Projects in this repository

- **food-ordering-app**  
  Full-stack MERN food ordering app with Stripe payments and Firebase auth setup.
- **login-register-form**  
  React login/register UI flow.
- **personal-portfolio**  
  React-based personal portfolio website.
- **react-form**  
  React multi-step form project.

## Quick start

From repository root:

```bash
npm install
```

Then run any project:

```bash
npm run start:login-register-form
npm run start:personal-portfolio
npm run start:react-form
npm run start:food-ordering-app
```

For food-ordering backend:

```bash
cd food-ordering-app/server
npm install
npm run start
```

## Build commands

```bash
npm run build:login-register-form
npm run build:personal-portfolio
npm run build:react-form
npm run build:food-ordering-app
```
